# Campus Notes

Campus Notes is a small project for keeping weekly college notes in one place. It is used to practise version control with Git and GitHub: branching, pull requests, code review, tags and releases.

## Contents
- `notes.txt`: weekly notes
- `README.md`: project overview and usage

## Getting started
1. Clone the repo:
   git clone https://github.com/<username>/vcs-campusnotes-<enrollment-no>.git
2. Open the folder and read `notes.txt`.

## Contributing
1. Fork the repo and create a branch: `feature/<name>-<change>`
2. Use Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`, `chore:`)
3. Open a pull request with a clear description.
How to run: open notes.txt
